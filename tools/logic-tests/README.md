# Автоматические проверки логики и базы данных

Эти проверки запускают **настоящий код приложения** (слой данных, правила выдачи и штрафов, отчёты, CSV,
подсказки поиска, данные главной страницы) на **настоящей SQLite** и сверяют результат.
Интерфейс WPF здесь не запускается. Проект не входит в решение `LibrarySystem.sln` и не влияет на сборку программы.

Что проверяется (около 200 проверок): вход и пароли (PBKDF2), выдача и все её правила, возврат и штрафы,
продление, утеря, пересчёт, оплата, транзакции (откат при сбое), SQL редактирования записей, отчёты на представлениях,
CSV, резервная копия, **все SQL-запросы экранов** с сортировкой и фильтрами по умолчанию, подсказки поиска,
данные главной, **триггеры и представления БД**, обновление старой базы до новой версии схемы и идемпотентность обновления.

## Запуск (Linux или WSL в Windows)

```bash
sudo apt install dotnet-sdk-8.0 libsqlite3-0 python3
cd tools/logic-tests
python3 extract_configs.py      # достаёт SQL и настройки экранов из исходников
dotnet run                      # в конце: «ИТОГО: проверок пройдено N, провалено 0»
```

Тестовая база создаётся во временной папке и не затрагивает вашу рабочую `library.db`.
